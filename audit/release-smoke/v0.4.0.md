## One assertion was wrong before the server was

`refresh_field_cache` first read as a failure. It was not: the tool
succeeded and refreshed all three resources, and the check asserted
`errors == 0` against a field that is `omitempty` and therefore absent
when zero. `None != 0`, so a working tool was called broken.

Recorded because it is the same shape as the defects this release's
tests were written to remove — an assertion that does not match the
contract it claims to check — and because the first instinct on a red
smoke is to look at the server.
