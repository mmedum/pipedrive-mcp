## Claude Code smoke

The maintainer registered the build under test in Claude Code with
local scope and ran one prompt. The prompt asked for `whoami` and a
dry-run `manage_deal` create in the test pipeline.

- `whoami` answered with the signed-in user, the workspace, the
  timezone and the locale.
- The dry-run create sent nothing. The reply named what a real create
  would set: the title, the signed-in user as owner (no owner was
  named), the workspace's default currency, the pipeline's first stage,
  and status open. Before this release, the owner, currency and stage
  showed as zero values.

The planned second prompt, a search, was not run. The search-term
change concerns logs, which a chat session does not show;
`TestClient_NoLogOrErrorCarriesTheSearchTerm` holds it.
