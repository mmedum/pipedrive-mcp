## `/code-review medium`

Eight findings. Five fixed, two written down in `docs/architecture.md`, one declined:

1. **The gate read an ignore entry only written goos-then-goarch.** The same entry in the other order was not applied, and the gate would report six archives while the release shipped five. The gate now refuses any ignore list: the family builds every pair of its two lists and never needs one.
2. **A stale name with a placeholder or no extension went unseen,** such as `pipedrive-mcp-X.Y.Z-linux-amd64` in prose. The old dashed form is refused in any spelling: a version, `X.Y.Z` or `<version>` after a dash.
3. **The Markdown under `.github/` was not scanned.** It is now.
4. **The matrix was read from the first `goos:` anywhere in the file.** It is read from the builds block alone, and a second build is refused.
5. **`emulated()` had no caller outside its test.** It is gone.
6. **Written down:** nothing cross-compiles before a tag, here or in any sibling, so a change that fails to build on windows/arm64 fails only in the release job.
7. **Written down:** a `name_template` written as a `|` block would render with a newline, which the gate joins with a space. The template is a `>-` line.
8. **Declined:** the archive rename was flagged as needing `**Breaking:**`. This project's contract is the MCP tool surface (the CHANGELOG preamble), and 1.2.0 renamed the bundle and the checksum file the same way, under Changed with a note for scripts. The entry carries that note.

Each fix was broken once in the code and its test failed: an ignore list in either order, a second build, the `.github/` scope, the old form in prose, and the de-duplication against a full archive name.

## `/simplify`

The four angles were run inline rather than by four agents, since agents were at their usage limit that day. No change beyond the code review's: the gate reuses `readWorkflows`, `indentOf` and `withoutComment` from `pins.go` and `modulePath` from `mcpregistry.go`, and reads a handful of files once per run. Reading `.goreleaser.yaml` with regular expressions rather than a YAML parser is kept, since `gopkg.in/yaml.v3` reaches this module only indirectly; the refusals in 1 and 4 are what bound it.
